Your Flow prompt will appear here Just type a keyword and press the button. The AI writes the story, designs the characters and plans every shot.
  1. Open Google Flow → New project, and set the aspect ratio to match.
  2. Quick way: copy the Flow prompt and paste it into Text to Video with Veo (audio on). Done.
  3. If Flow makes only one short clip (Veo renders about 8 seconds per generation), use the Per-scene prompts tab: paste scene 1, then scene 2, and so on. Add them in order in Scenebuilder, or use Extend.
  4. For the best face consistency, first generate the character images from Characters & places. Then use Ingredients to Video and attach them to each scene.
  5. Make 2–4 takes and keep the best. Don't change the character text, because it's the same in every prompt on purpose.
